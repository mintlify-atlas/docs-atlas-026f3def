AuthKit React Router is the official WorkOS library for adding authentication and session management to React Router 7+ applications. It provides drop-in loader helpers that handle the full OAuth flow — PKCE code exchange, encrypted cookie sessions, automatic token refresh, and sign-out — so you can focus on building your app rather than auth infrastructure.

## What AuthKit React Router provides

AuthKit React Router wraps the WorkOS User Management API and exposes a small, focused set of React Router loader helpers. The core building blocks are:

- **`authkitLoader`** — wraps your route loaders to automatically verify and refresh the user's session, exposing `user`, `sessionId`, `organizationId`, `role`, `permissions`, `entitlements`, `featureFlags`, and `impersonator` to your components.
- **`authLoader`** — handles the OAuth callback route, exchanging the authorization code for tokens and writing the encrypted session cookie.
- **`getSignInUrl` / `getSignUpUrl`** — build PKCE-protected authorization URLs for your login and signup redirect routes.
- **`signOut`** — terminates the session and redirects the user.

## How it works

<Steps>
  <Step title="Install the package">
    Add `@workos-inc/authkit-react-router` to your React Router 7+ project.

    ```bash
    npm install @workos-inc/authkit-react-router
    ```
  </Step>
  <Step title="Set environment variables">
    Add your WorkOS credentials to `.env.local`. Three variables are required; `WORKOS_API_KEY` is optional for public-client (keyless) mode.

    ```bash .env.local
    WORKOS_CLIENT_ID="client_..."
    WORKOS_REDIRECT_URI="http://localhost:5173/callback"
    WORKOS_COOKIE_PASSWORD="<at-least-32-character-secret>"
    WORKOS_API_KEY="sk_test_..."  # optional
    ```
  </Step>
  <Step title="Add the callback route">
    Create a route that matches your redirect URI and export `authLoader` as its loader.

    ```ts app/routes/callback.ts
    import { authLoader } from '@workos-inc/authkit-react-router';

    export const loader = authLoader();
    ```
  </Step>
  <Step title="Protect your routes">
    Wrap any route loader with `authkitLoader` to get authenticated user data — or redirect automatically with `ensureSignedIn`.

    ```tsx app/routes/dashboard.tsx
    import { type LoaderFunctionArgs, useLoaderData } from 'react-router';
    import { authkitLoader } from '@workos-inc/authkit-react-router';

    export const loader = (args: LoaderFunctionArgs) =>
      authkitLoader(args, { ensureSignedIn: true });

    export default function Dashboard() {
      const { user } = useLoaderData<typeof loader>();
      return <h1>Welcome, {user.firstName}!</h1>;
    }
    ```
  </Step>
</Steps>

<Note>
  AuthKit React Router targets React Router 7+ in **framework mode** (i.e., Remix-style with loaders and server-side rendering). Library mode support is planned for future releases.
</Note>
